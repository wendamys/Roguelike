При запуске встречает сгенерированный мир   (может не поместиться на экран)

1. Основная навигация
- @ - иконка игрока
- (*) - переход на след уровень
- z - зомби
- o - огр
- g - призрак
- s - змея
- v - вампир
- m - мимик
- E - еликсир
- W - оружие
- S - свитки
- F - еда

кнопки для передвижения: WASD
кнопки для предметов:
    
- e - эликсир
- h - свитки
- j - еда
- k - оружие

После выбора типа предмета нажимаем 1-9 для выбора непосредственно самого предмета в рюкзаке

2. Над полем высвечивается информация по предметам/противникам/статусе боя и тд
3. Под полем высвечиваются статус игрока
