1. Создать два класса: "Controller" и "UIView", всю лоигику из main перенести в эти классы:
    - В "Controller" будет описан механизм взаимодействия консоли с игрой
    - В "UIView" будет описана логика отрисовки игры
    - В Main оставить только запуск игры

2. Отрисовка игры будет иметь вид:
    - В левой часть экрана отрисовка поля игры
    - В левой нижней части экрана посередине поля отрисовка уровня игры
    - В нижней также кол-во предметов и врагов, и лвл
    - В правой верхней части отображение информации о игроке(без уровня)
    - В правой средней части отрисовка инвентаря
    - В правой нижней части отрисовка логов боя

3. Создать два класса: "StartScreen" и "EndScreen":
    - "StartScreen" будет отвечать за отрисовку стартового экрана
    - Кнопки стартового экрана: "Start game", "Load game", "Exit"
    - Добавить ввод имени игрока при нажатии старт гейм
    - Лоад гейм, загрузка с последней позии игрока и полностью его данных
    - "EndScreen" будет отвечать за отрисовку экрана конца игры и вывод "score"
